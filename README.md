# UW-AMATH-582: Computational Methods for Data Analysis
## Course Purpose:
This course offers an overview of various computational tools for analysis of data sets and extraction of meaningful information. The course is split into two parts: Linear methods, which covers a lot of the classical approaches to data analysis that are broadly based on linear analysis and approximation theory; and nonlinear methods, which covers more advanced methods that rely on nonlinear transformations and approximation theory. 

## Course Scope:
1. Fast Fourier Transform Analysis
2. Wavelet Transform Analysis
3. Singular Value Decomposition & Principal Component Analysis
4. Supervised Learning (regression and classification) -- Reproducing Kernel Hilbert Spaces
5. Unsupervised Learning -- Spectral Clustering

## Homework assignments:

1. Submarine Tracking (FFT)
2. Image Edge map (Wavelets)
3. Background removal from video (PCA)
4. Wine Classification (supervised learning)
5. Politician Clustering (unsupervised learning)
